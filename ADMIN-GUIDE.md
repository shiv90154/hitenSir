# BharatTrip Admin Panel Guide

**Login:** https://www.bharattrip.net/admin/login
Email aur password aapko alag se bheje ja rahe hain. Login ke baad left side me menu dikhega. Mobile pe upar wale menu button se khulta hai.

**Sabse important niyam:** Har content (package, blog, destination wagairah) me **Status** hota hai.

- **Draft** = sirf admin me save hai, website pe nahi dikhega.
- **Published** = website pe live ho jayega.

Naya content pehle Draft me save karke check kar sakte ho, phir Published kar do.

---

## 1. Dashboard

Login ke baad pehla page. Yahan site ka quick overview dikhta hai, jaise kitna content hai aur naye enquiries.

## 2. Content

### Destinations
Shehar ya jagah ka main page, jaise Shimla, Manali, Kasol. Isme naam, chhota description, poori detail, kab jana best hai, kaise pahunche, travel tips aur cover photo daalte hain. "Nearby destinations" me pass wali jagah chun sakte ho, wo us page pe apne aap dikhengi.

### Places
Kisi destination ke andar ki khaas jagah, jaise Shimla ke andar Mall Road ya Jakhoo Temple. Har place ko ek destination se jodna padta hai.

### Packages
Sabse zaroori section, yahin se aapke tour packages bante hain. Isme ye bharna hai:

- Name aur destination
- Short description (card pe dikhta hai) aur poori description
- Duration (jaise 5 Nights / 6 Days) aur **Price from (₹)**
- Photos (kai photos, package page pe gallery banti hai)
- Highlights, Included, Excluded (har line me ek point)
- **Day-by-day itinerary:** har din ka title aur detail
- Category chun sakte ho (jaise Honeymoon, Family)

Customer isi page se WhatsApp ya Call kar sakta hai, ye number Settings se aata hai.

### Blogs
Travel articles likhne ke liye. Title, Excerpt (chhota summary), poora text (Body), featured image, categories aur tags. Google me aane ke liye achhe blog bahut kaam aate hain.

Body me formatting:

- Heading ke liye `## Heading`
- Bold ke liye `**text**`
- List ke liye `- point`

### Guides
Blogs jaisa hi hai, par lambe travel guides ke liye (jaise "Shimla ka poora guide").

### Things To Do
Activities, jaise Paragliding, Rafting, Trekking. Duration, price, kaunsa season best hai, difficulty (Easy/Medium/Hard) aur safety info likh sakte ho.

### Categories
Packages, Blogs ya Activities ko group karne ke labels, jaise Honeymoon, Adventure. Yahan naye labels bana sakte ho.

## 3. Media

### Media Library
Website ki saari photos yahin store hoti hain. Photo upload karo aur uska "alt text" (photo ka chhota description) likh do, isse Google me bhi help milti hai. Kisi bhi form me photo chunte time yahi library khulti hai. Photo delete karoge to wo server se bhi hat jayegi.

### Galleries
Photos ka collection (album), jaise "Manali Winter 2026". Gallery page pe dikhta hai.

## 4. Website (site ka look)

### Homepage
Home page ko control karne ki jagah:

- Har section on/off kar sakte ho: Featured Destinations, Packages, Things To Do, Popular Places, Blog, Gallery, Why Choose Us, Testimonials, FAQs
- Hero (sabse upar ka bada hissa): Headline, Subheading aur background image badal sakte ho
- Marquee (chalti hui line): uska text aur speed badal sakte ho

### Navigation
Website ke upar wale menu aur footer ke links. Naya link jodna, hatana ya order badalna yahin se hota hai.

### FAQs
Customers ke aam sawal aur jawab. Ye homepage pe dikhte hain.

### Testimonials
Customers ke reviews (naam, shehar, rating aur review text). Homepage pe pehle 3 dikhte hain.

## 5. Leads

### Enquiries
Website ke Contact form se jo bhi customer message bhejta hai, wo yahan aata hai. Har enquiry ka status set kar sakte ho:

**New → Contacted → In Progress → Converted → Closed**

Isse pata rahta hai kis customer se baat ho gayi. Ye roz check karna sabse zaroori hai.

## 6. SEO aur Settings

### Global SEO
Google search me site ka default title aur description. Jab kisi page ka apna SEO na ho to yahi use hota hai.

### Settings
Site ki basic jaankari:

- Site name aur tagline
- Contact email, phone (pehla number WhatsApp ke liye bhi use hota hai) aur second phone
- Address
- Social media links (Facebook, Instagram, Twitter, YouTube)

---

## Naya package kaise daalein (step by step)

1. Pehle **Media Library** me package ki photos upload karo.
2. **Packages → New** pe jao.
3. Name, destination, duration aur price bharo.
4. Photos chuno, phir Highlights, Included, Excluded likho.
5. Itinerary me har din ka detail daalo.
6. Pehle **Draft** me save karo aur check karo, phir **Published** karke Save dabao.
7. Website pe `www.bharattrip.net/packages` kholke dekh lo.

## Zaroori tips

- Photos saaf aur achhi quality ki daalo, package ki photos sabse zyada asar karti hain.
- Kuch bhi badalne ke baad **Save** dabana mat bhoolna. Save hone par upar message aata hai.
- Delete karne se pehle soch lo, delete wapas nahi hota. Confirm ka box aayega.
- Password kisi ko mat batao, aur pehle login ke baad usko badal lo.
- Kuch samajh na aaye ya problem aaye to developer ko batao.
